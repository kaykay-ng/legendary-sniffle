Exercise 2.10 — Ship an Explorable

Stub Pairing: why does cleaning up a configuration model's self-loops and parallel edges cost hubs so much more than everyone else? Pick a degree sequence, shuffle its stubs, and watch. Every self-loop (red) and parallel edge (orange, dashed) removed after pairing is a piece of degree quietly stripped from whichever two nodes happened to be on the losing end — and the busier a node's stub list, the more chances it gets to lose.

Switch to Heavy-tailed and click Run 100 Trials: the bar chart should look unmistakably like the scatter plot in Exercise 2.8 — edges lost climbing steeply with degree. Switch to Homogeneous and run it again: with no node standing out in stub count, the losses flatten out almost completely. That contrast is the mechanism behind 2.8's 0.11-vs-0.15 clustering gap, made clickable.

Exercise 2.11 — Go Nuts With Your LLM

The open-ended weekly write-up. Exercise 2.8's Part 2 predicted what would happen to the "39% reciprocated, 13× higher than chance" claim under a proper null — but never ran it. This closes that loop with real numbers.

Does the reciprocity effect survive a degree-preserving null?

The Marvel network's directed graph (303 nodes, 1,784 edges) has 39.2% overall reciprocity. The naive same-density null used in the flawed claim predicts just 1.9% — a 20× gap, in the same spirit as the exercise's "13×" framing. But that null treats every node as equally likely to link anywhere, which Marvel's hub-heavy degree sequence makes a poor assumption.

Naive same-density null
predicted reciprocity1.9%
real / null ratio20.1×
Directed configuration model (100 trials)
mean reciprocity5.1%
z-score57.2
empirical p-value0.0099
real / null ratio7.6×
The prediction holds up. Once each node's exact in- and out-degree is preserved, the null's own reciprocity climbs from 1.9% to 5.1% — mechanically, because hubs have so many stubs that some of them land back on each other by chance alone. The real network's excess shrinks from a dramatic 20× down to about 8×. Still highly significant (z ≈ 57) — real reciprocation behavior is genuinely present — but a fraction of the original inflated headline.
The general lesson: a "13×" or "20×" number is often mostly a statement about which null you picked, not about the network. Before repeating a multiplier like that in a paper, ask what baseline produced it — and whether that baseline controlled for the one thing (here, degree heterogeneity) that would have explained most of the gap away.
